# Skillz
This is an education-based web application that will act as a "public database" of useful articles while learning a new topic. There will be three main categories including sports, art, and musical instruments. This app also hosts reviews and ratings of various articles in which users can search through to find resources on new skills they are interesting in. Ratings (upvotes and downvotes) will be used to ensure that the articles provided are of high quality. This app will be useful for anyone who is unsure of how to develop a new skill, as it can be overwhelming to do so.

## Technologies Used
* Backend: PHP 8.5
* Database: MySQL (Google Cloud SQL)
* Hosting: Google App Engine (Standard Environment)

## Features

* Public database of articles based on subject area
* Reviews
* Ratings
* Votes
* Accounts
* Friends
